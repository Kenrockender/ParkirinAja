# QR Slot Parkir — Parkir Binus (32 QR)

Satu QR unik untuk setiap slot parkir di Gedung Parkir Anggrek, Lantai 1:
Baris A (A-01 … A-18) dan Baris B (B-01 … B-14) — total **32 QR**.

## Isi folder

| File | Keterangan |
|------|------------|
| `ParkirBinus-QR-Slot-A4-Print.pdf` | Siap cetak — A4, 4 halaman, 8 kartu per halaman (grid 2×4), garis potong putus-putus |
| `PNG/QR-A-01.png` … `QR-B-14.png` | 32 kartu PNG individual (±95×66 mm @ 300 DPI) — cetak satuan / laminate |
| `ParkirBinus-QR-Slot-PNG.zip` | Semua 32 PNG dalam satu arsip |

## Format kode

Setiap QR berisi payload `PB-<nomor slot>` (contoh: `PB-A-07`).
Payload ini langsung dikenali scanner di aplikasi (walk-in / check-in / check-out)
dan juga bisa diketik manual di kolom "ketik kode slot".

## Cara pakai

1. Cetak PDF (pilih *Actual size* / 100%, jangan *Fit to page*).
2. Potong tiap kartu mengikuti garis putus-putus.
3. Tempel/laminate di tiap slot sesuai nomornya — A-01 di slot A-01, dst.

Operator juga bisa mencetak/mengunduh QR langsung dari aplikasi:
**Masuk sebagai Operator → seksi "QR Slot Parkir" → Cetak Semua / Unduh PNG.**
